# Αντιστοιχία εργασιών Fiona με κατηγορίες tracker



Οι παρακάτω τύποι εργασίας αντιστοιχίζονται αυτόματα στην ελληνική κατηγορία του tracker και παίρνουν τους αντίστοιχους πόντους:



* `FTTH Activation` → Ε**γκατάσταση Οπτική**ς — **50 πόντοι**
* `On-Site Support FTTH` → **Βλάβη Οπτική**ς — **15 πόντοι**
* `Cabling repair and maintenance` → **Καλωδίωση / Νέα εγκατάσταση** — 15/**50 πόντοι (Εάν βρει τι λεξη εγινε εγκατασταση η εγινε οδευση παει 50 ποντοι)**
* `FTTH Additional Cabling` → Διπλό Συνεργείο — 100 πόντοι**
*



* `CPE Installation FWA` → **Εγκατάσταση 5G** — **35 πόντοι**
* `On-Site Support FWA` → **Βλάβη 5G** — **15 πόντοι**



* `NGA Activation` → **Εγκατάσταση χαλκού** — **15 πόντοι**
* `CPE Installation NGA` → **Εγκατάσταση χαλκού** — **15 πόντοι**
* `CPE Installation LLU` → **Εγκατάσταση χαλκού** — **15 πόντοι**
* `On-Site Support NGA` → **Βλάβη χαλκού** — **15 πόντοι**
* `On-Site Support LLU` → **Βλάβη χαλκού** — **15 πόντοι**
* `SI Bridging` → **Βλάβη χαλκού** — **15 πόντοι**
* `CO Visit` → **Βλάβη χαλκού** — **15 πόντοι**



* `CPE Installation DTH TV` → **Δορυφορική εγκατάσταση** — **25 πόντοι**
* `On-Site Support DTH TV` → **Δορυφορική βλάβη** — **18 πόντοι**



* `CPE Installation` → **Εγκατάσταση EON** — **5 πόντοι**



* `Combined Wind-AP` → **Συνδιαστικό** — **15 πόντοι**
* `Combined Visit OTE-WIND` → **Συνδιαστικό** — **15 πόντοι**
* `Combined LLU Visit OTE-WIND` → **Συνδιαστικό** — **15 πόντοι**



* **Άλλες εργασίες** — 5 πόντοι





## Επιλογές στη χειροκίνητη αλλαγή αντιστοίχισης



Στην αλλαγή κατηγορίας μιας εργασίας εμφανίζονται οι παρακάτω επιλογές:



### Εγκαταστάσεις



* **Εγκατάσταση** **οπτικής**  — 50 πόντοι
* **Εγκατάσταση 5G** — 35 πόντοι
* **Εγκατάσταση Δορυφορικού** — 25 πόντοι
* **Εγκατάσταση EON** — 5 πόντοι



### Βλάβες



* **Βλάβη οπτικής** — 15 πόντοι
* **Βλάβη 5G** — 15 πόντοι
* **Βλάβη** **Δορυφορικού** — 18 πόντοι
* **Βλάβη χαλκού** — 15 πόντοι



### Συνδιστικά



* **Συνδιαστικό** — 15 πόντοι





### Άλλες εργασίες



* **Άλλες εργασίες** — 5 πόντοι



Επιπλέον, υπάρχει η επιλογή **Χωρίς αντιστοίχιση**, η οποία αφαιρεί την αντιστοίχιση κατηγορίας.

* Οι κατηγορίες **Καλωδίωση / Νέα εγκατάσταση** και **SOHO** δεν προσφέρονται για αλλαγή σε αυτές. Αν κάποια από τις δύο είναι ήδη η κατηγορία της εργασίας, παραμένει ορατή στον επιλογέα ως τρέχουσα κατηγορία. Η καλωδίωση, ωστόσο, αντιστοιχίζεται αυτόματα όπως φαίνεται παραπάνω.
